# MS007 客户登记系统

这是 MS007 的正式主仓库。目标是长期承载 10,000–20,000+ 纯文字客户资料，并预留继续扩展到更大规模的能力。

## 当前架构

- Cloudflare Workers：后端 API
- Cloudflare D1：客户、业务员、动态字段、进度、配置、日志
- Cloudflare Static Assets：前端页面
- GitHub：唯一主代码仓库
- 不把客户数据写进 GitHub
- 客户列表服务端分页，每页默认 50 条
- 搜索、筛选、统计全部在服务端完成
- 动态登记字段、动态进度、客户列表字段、左右侧栏配置全部保存在数据库
- 管理员可统一配置管理员/业务员左侧栏；业务员只读取并自动同步
- 客户卡片整张背景显示进度百分比
- 删除采用软删除，保留审计日志

## 管理员容量/费用提醒

管理员后台会显示“系统容量与费用”，用普通中文提示：
- 当前客户数量与估算数据量
- 当前容量状态：正常 / 注意 / 建议升级 / 尽快升级
- 哪项资源接近限制
- 需要升级哪个服务
- 当前免费额度与升级入口
- 预计费用

2026-10-01 的 Cloudflare 免费层参考值：
- D1 单个数据库上限：500 MB
- D1 账户总存储：5 GB
- D1 每日读取：5,000,000 行
- D1 每日写入：100,000 行
- Workers 每日请求：100,000 次
- Workers Paid 最低费用：5 USD/月

这些值在系统中作为“参考快照”，后续可由管理员配置更新，避免平台价格变化后写死。

## 安全原则

- 密码使用 PBKDF2-SHA256 哈希保存
- 登录 Session 保存在数据库并设置 HttpOnly Cookie
- 业务员权限在后端强制限制，只能读取自己的客户
- 管理员可读取全部客户
- 所有关键修改写入 audit_logs
- 客户删除为软删除
