# MS007 第一阶段设计

## 权限
- admin：查看全部客户、管理业务员、字段、进度、左右侧栏、容量与费用
- sales：只能查看和编辑分配给自己的客户；不能修改系统级设置

## 性能
- 客户列表默认每页 50 条
- 使用游标分页，不使用大 OFFSET
- 进度百分比在勾选时立即回写 customers，列表不重复统计
- 列表动态字段只读取管理员设置为“列表显示”的字段
- 常用查询建立索引
- 删除客户使用 deleted_at 软删除

## 左侧栏
管理员管理 sidebar_items：
- audience：admin / sales / all
- 名称
- 图标
- 链接
- 当前页/新窗口
- 启用/停用
- 排序
- 分组

客户端每次加载读取当前配置；后续加入版本号轮询/实时同步时，只刷新侧栏配置，不刷新整页。

## 容量与费用
系统按客户核心字段 + 动态字段文字长度估算业务数据量，并按免费 D1 单库 500MB 做预警：
- <70%：正常
- 70–84%：注意
- 85–94%：建议升级
- >=95%：尽快升级

管理员页面同时显示：
- 服务商：Cloudflare
- 数据库：D1
- 当前套餐参考
- 需要升级时：升级到 Workers Paid
- 费用参考：最低 5 USD/月（2026-10-01 快照）
- 付款/升级入口

实际平台价格可能变化，所以日期和额度保存在 system_settings，可后续更新。
