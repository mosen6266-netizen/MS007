你现在负责把 MS007 从“新账号终极恢复包”部署到全新的 GitHub + Cloudflare 环境。请直接执行，不要让我重复项目历史。

【目标】
在新的 Google / ChatGPT / GitHub / Cloudflare 账号下重新建立与原 MS007 功能、界面、Logo、按钮逻辑一致的系统；客户与业务数据随后用用户提供的 MS007 V3 备份恢复。

【先做】
1. 确认当前 GitHub 连接的是用户的新 GitHub 账号。
2. 确认恢复包全部文件已经上传到新仓库，默认分支 main，且 .github/workflows/deploy.yml 存在。
3. 阅读 README_FIRST.txt、NEW_ACCOUNT_SETUP.md、RESTORE_V3_BACKUP.md、POST_RESTORE_CHECKLIST.md、docs/DEPLOYMENT.md、schema.sql、migrations/。
4. 运行 VERIFY_RECOVERY_PACKAGE.py；校验失败就先停止部署并说明缺少/变化了什么。

【严格安全规则】
- 不要求用户把 Cloudflare API Token、GitHub Token、密码、Telegram Bot Token 粘贴到聊天或提交进仓库。
- 密钥只让用户在官方 UI 的 Secrets/安全设置里填写。
- 不把 V3 业务备份提交到 GitHub，尤其是公开仓库。
- 已存在的生产 D1 不得删除、重建或用 schema.sql 覆盖；只有全新空 D1 才能 bootstrap schema.sql。
- 已有数据库的升级只使用 migrations/。
- 不修改客户数据来凑校验结果。

【新账号部署需要的 GitHub Actions Secrets】
- CLOUDFLARE_API_TOKEN
- CLOUDFLARE_ACCOUNT_ID
- BOOTSTRAP_TOKEN

指导用户在新 Cloudflare 账号创建权限足够部署 Workers 和管理 D1 的 API Token。Cloudflare UI/权限名称如有变化，先查当前官方说明再指导。
BOOTSTRAP_TOKEN 使用新的高强度随机值，只用于首次创建管理员，不是管理员登录密码。

Secrets 配置好后：
- 运行或重新运行 Deploy MS007 to Cloudflare。
- 工作流应自动创建 ms007-crm-staging 和 ms007-crm D1（不存在时）。
- 新 D1 才执行 schema.sql，随后应用 migrations。
- 确认 validate -> staging -> production 全部成功。
- 确认 /api/health 的 channel=production，version 对应部署 commit。
- 记录新的 production workers.dev 地址。

【首次管理员】
如果用户已经提供 V3：
- 在 V3 users section 找 role=admin 的 username/display_name。
- 首次管理员尽量使用相同 username/display_name，密码设为新的安全密码。
这样恢复时旧管理员身份映射最干净。
如果尚未提供 V3，可以先部署，但不要猜旧管理员用户名。

【V3 恢复】
- V3 不上传到 GitHub。
- 在新 MS007 的“数据备份与恢复”页面选择 V3 文件。
- 必须先通过 SHA-256、数量校验和完整预演，确认无冲突后再正式恢复。
- 恢复后业务员账号可能保持停用，这是安全设计；管理员逐个设置新密码并启用需要登录的账号。
- Telegram Bot Token 不会从备份恢复，必须重新填写。
- 其他非秘密 Telegram 设置/路由、客户、进度、字段、侧栏、列表、仪表盘、系统设置、操作记录和 Telegram 发送历史应由 V3 恢复。

【最终验收】
逐项完成 POST_RESTORE_CHECKLIST.md。
以下全部通过后才能报告“恢复完成”：
1. GitHub Quality Check 成功；
2. Cloudflare staging/production 部署成功；
3. /api/health 正常；
4. V3 完整性检查和恢复成功；
5. 客户数量、字段、进度、业务员、侧栏、列表设置、仪表盘设置与备份一致；
6. Logo、登录页、管理员端、业务员端正常；
7. Telegram 如启用，Bot Token 已重新配置且测试发送成功；
8. 没有未应用 migration。

遇到报错时直接定位并修复安全的代码/部署问题；任何可能覆盖或删除生产数据的操作必须停止并先说明风险。
